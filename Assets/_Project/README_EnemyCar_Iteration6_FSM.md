### Крок 2: Налаштувати Combat в інспекторі

На `EnemyCarController` з'явились нові поля:

| Поле | Опис | Рекомендація |
|------|------|--------------|
| Attack Range | Дистанція для переходу в атаку | 30 |
| Fire Rate | Інтервал між пострілами (секунди) | 0.5 |
| Muzzle Flash | ParticleSystem для спалаху | Створи або пропусти |
| Fire Sound | AudioClip звуку пострілу | Додай або пропусти |
| Fire Volume | Гучність пострілу | 0.8 |

## FSM логіка

```
┌─────────────┐      Player в радіусі атаки      ┌──────────────┐
│   DRIVING   │ ─────────────────────────────▶  │  ATTACKING   │
│             │ ◀─────────────────────────────  │              │
└─────────────┘      Player поза радіусом       └──────────────┘
```

### DrivingState
- Їде по waypoints
- Тримається попереду гравця
- Швидкість = 100%

### AttackingState
- Продовжує їхати
- Швидкість = 80%
- Стріляє кожні `FireRate` секунд
- ParticleSystem + звук

---

## Як тестувати

1. Запусти гру
2. Під'їдь до ворога на ~30м
3. Ворог має почати стріляти (партикли + звук)
4. Від'їдь далі — ворог перестає стріляти

### Перевірки

| Тест | Очікування |
|------|------------|
| Ворог далеко | Їде, не стріляє |
| Ворог близько (<30м) | Їде + стріляє |
| Під'їзд/від'їзд | Переходить між станами |

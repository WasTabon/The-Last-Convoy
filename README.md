## Короткий опис проєкту

**The Last Convoy** - тривимірна аркадна відеогра у жанрі *vehicular combat* (бойовий транспорт) на ігровому рушії Unity. Ключова механіка - **незалежне (роздільне) керування рухом транспортного засобу та обертанням турелі** через два окремі пристрої введення: клавіатура керує рухом автомобіля, миша - напрямком прицілу й вогню турелі. Гра побудована навколо виду від першої особи з кабіни водія та лінійної структури рівнів у постапокаліптичному сеттингу.

Проєкт реалізує повний ігровий цикл: керування станами гри, обробку вводу, фізику руху транспорту над нерівним рельєфом, систему стрільби з пулом ефектів та штучний інтелект ворогів зі системою їх появи. Архітектура побудована на патернах **скінченного автомата (FSM)** і **Model-View-Presenter (MVP)** з використанням фреймворку ін'єкції залежностей **Zenject**.

## Встановлення та запуск

> **Примітка для членів екзаменаційної комісії:** усі необхідні асети та пакети (DOTween, Zenject, Gaia тощо) вже включені до репозиторію - нічого додатково завантажувати чи докуповувати не потрібно.

1. Встановіть **Unity Hub**: https://unity.com/download
2. Через Unity Hub встановіть **Unity 2022.3.62f2** з модулем збірки **Windows Build Support (IL2CPP)**.
3. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/WasTabon/bachelor-Maiorov.git
   ```
4. У Unity Hub натисніть **Add → Add project from disk** і виберіть кореневу папку клонованого проєкту.
5. Відкрийте проєкт. Під час першого відкриття Unity автоматично імпортує наявні в репозиторії асети та пакети - зачекайте завершення.
6. У вікні **Project** відкрийте головну сцену: `CutsceneScene`.
7. Натисніть **Play** ▶ у верхній панелі редактора для запуску гри.

### Збірка білда вручну (за потреби)

1. У Unity відкрийте **File → Build Settings**.
2. Переконайтеся, що цільова платформа - **Windows x86_64**.
3. Додайте всі ігрові сцени до списку **Scenes In Build**.
4. Натисніть **Build**, виберіть вихідну папку та дочекайтесь завершення.

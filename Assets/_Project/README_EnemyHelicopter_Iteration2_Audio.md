## Как настроить

### Шаг 1: Заменить файлы

1. Замени `EnemyHelicopterConfig.cs` на новую версию из архива

2. Скопируй `EnemyHelicopterAudioView.cs` в:
   ```
   Assets/_Project/Scripts/Views/Enemy/
   ```

### Шаг 2: Обновить Config

Открой свой `EnemyHelicopterConfig` asset и настрой новые поля:

| Поле | Описание | Рекомендация |
|------|----------|--------------|
| **Rotor Loop Clip** | Звук вращения лопастей (loop) | Перетащи свой AudioClip |
| **Rotor Base Volume** | Базовая громкость | 0.7 |
| **Rotor Min Pitch** | Минимальный pitch | 0.9 |
| **Rotor Max Pitch** | Максимальный pitch | 1.1 |
| **Audio Min Distance** | Минимальная дистанция 3D звука | 5 |
| **Audio Max Distance** | Максимальная дистанция | 150 |
| **Audio Spatial Blend** | 0 = 2D, 1 = полный 3D | 1 |
| **Audio Doppler Level** | Эффект Доплера | 0.3 |
| **Low Pass Min Frequency** | LowPass при низкой скорости | 2000 |
| **Low Pass Max Frequency** | LowPass при высокой скорости | 6000 |

### Шаг 3: Добавить компонент на prefab

1. Открой prefab вражеского вертолёта
2. На **корневой объект** добавь компонент `EnemyHelicopterAudioView`
3. В поле **Rotor Audio Position** перетащи Transform откуда должен идти звук (например объект лопастей или отдельный пустой объект над вертолётом)

### Шаг 4: (Опционально) Создать точку звука

Если хочешь чтобы звук шёл из конкретной точки:
1. Создай пустой дочерний объект в prefab'е, назови `AudioPoint_Rotor`
2. Расположи его над вертолётом (где лопасти)
3. Перетащи в поле `Rotor Audio Position`

Если оставишь поле пустым — звук будет идти из центра вертолёта (появится Warning в консоли).

## Как тестировать

### Ожидаемый результат:

1. **Запусти игру**
2. Вражеский вертолёт должен:
   - Издавать звук лопастей
   - Звук 3D — громче когда камера ближе, тише когда дальше
   - Pitch меняется в зависимости от скорости
   - Громкость немного увеличивается при поворотах
   - LowPass фильтр меняет "яркость" звука в зависимости от скорости

### Проверки:

| Тест | Ожидание |
|------|----------|
| Приблизить камеру к врагу | Звук громче |
| Отдалить камеру от врага | Звук тише |
| Враг ускоряется / летит быстро | Pitch выше, звук "ярче" |
| Враг поворачивает | Небольшое увеличение громкости |

### Если что-то не работает:

| Проблема | Решение |
|----------|---------|
| Нет звука | Проверь что Rotor Loop Clip назначен в Config |
| Ошибка в консоли про clip | Назначь AudioClip в EnemyHelicopterConfig |
| Звук не 3D (одинаковая громкость везде) | Проверь Audio Spatial Blend = 1 в Config |
| Звук слишком тихий издалека | Увеличь Audio Max Distance |

## Параметры аудио (детально)

### Pitch
- При низкой скорости: `RotorMinPitch` (0.9)
- При крейсерской скорости: `RotorMaxPitch` (1.1)
- Плавный переход между ними

### Volume
- База: `RotorBaseVolume`
- +10% при максимальной скорости
- +15% при сильных поворотах
- Максимум: 1.0

### LowPass Filter
- Приглушает высокие частоты на низких скоростях
- На высокой скорости звук "ярче"
- Создаёт эффект того что вертолёт "раскручивается"

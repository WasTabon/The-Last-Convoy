## Как настроить

### Шаг 1: Скопировать/заменить файлы

```
Assets/_Project/Scripts/
├── Configs/
│   └── PlayerCarCameraConfig.cs        [ДОБАВИТЬ]
├── Gameplay/
│   └── Installers/
│       └── PlayerCarInstaller.cs       [ЗАМЕНИТЬ]
└── Views/
    └── Player/
        └── PlayerCarCameraView.cs      [ДОБАВИТЬ]
```

### Шаг 2: Создать Camera Config

1. ПКМ → Create → LastConvoy → Configs → PlayerCarCamera
2. Назови `PlayerCarCameraConfig`
3. Настрой параметры (дефолтные уже рабочие)

### Шаг 3: Создать камеру в кабине

1. Открой prefab/объект машины
2. Создай пустой дочерний объект → назови `CameraRig`
3. Расположи его там где должна быть голова водителя (примерно)
4. Перемести **Main Camera** из сцены внутрь `CameraRig` (сделай дочерним)
5. Сбрось позицию камеры в (0, 0, 0) относительно CameraRig

### Шаг 4: Добавить компонент камеры

1. На объект `CameraRig` добавь компонент `PlayerCarCameraView`
2. Zenject автоматически инъектирует зависимости

### Шаг 5: Обновить Installer

1. В `PlayerCarInstaller` появилось новое поле **Camera Config**
2. Перетащи созданный `PlayerCarCameraConfig`

## Как тестировать

### Ожидаемый результат:

1. **Запусти игру**
2. Камера теперь внутри машины (вид из кабины)
3. При езде — небольшая тряска камеры
4. При повороте — камера слегка наклоняется в сторону поворота
5. Стоя на месте — камера стабильная

### Проверки:

| Тест | Ожидание |
|------|----------|
| Стоя на месте | Камера неподвижна |
| Едешь прямо | Лёгкая тряска |
| Едешь быстро | Тряска сильнее (но не больше max) |
| Поворот влево (A) | Камера наклоняется вправо |
| Поворот вправо (D) | Камера наклоняется влево |
| Отпустить руль | Камера плавно возвращается |

### Если не работает:

| Проблема | Решение |
|----------|---------|
| Камера не двигается с машиной | Камера должна быть дочерним объектом машины |
| Нет тряски | Проверь что Camera Config назначен |
| Слишком сильная тряска | Уменьши Shake Amount By Speed |
| Вид снаружи машины | Подвинь CameraRig внутрь кабины |

## Параметры PlayerCarCameraConfig

### Position

| Параметр | Описание | Дефолт |
|----------|----------|--------|
| Camera Offset | Смещение камеры от CameraRig | (0, 1.2, 0.3) |

### Shake (тряска)

| Параметр | Описание | Дефолт |
|----------|----------|--------|
| Shake Amount By Speed | Множитель тряски от скорости | 0.02 |
| Shake Frequency | Частота тряски | 15 |
| Max Shake Amount | Максимальная амплитуда | 0.05 |

### Tilt (наклон)

| Параметр | Описание | Дефолт |
|----------|----------|--------|
| Tilt Amount By Turn | Градусы наклона при повороте | 2 |
| Tilt Smoothing | Плавность наклона | 5 |

## Советы по настройке

**Позиция камеры:**
- X = 0 — по центру машины
- Y = 1.2 — высота головы водителя
- Z = 0.3 — немного вперёд к лобовому стеклу

**Тряска:**
- Слишком много — укачивает
- Слишком мало — не чувствуется езда
- Рекомендую: 0.01-0.03

**Наклон:**
- Добавляет ощущение поворота
- 2-3 градуса достаточно для эффекта без дискомфорта

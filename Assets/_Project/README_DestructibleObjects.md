# Разрушаемые объекты

## Что добавлено

| Путь | Описание |
|------|----------|
| `Scripts/Configs/DestructibleObjectConfig.cs` | ScriptableObject с настройками |
| `Scripts/Gameplay/DestructibleObject.cs` | Компонент разрушаемого объекта |

---

## Как настроить

### Шаг 1: Скопировать файлы

```
Assets/_Project/Scripts/
├── Configs/
│   └── DestructibleObjectConfig.cs
└── Gameplay/
    └── DestructibleObject.cs
```

### Шаг 2: Создать Config

1. ПКМ → Create → LastConvoy → Configs → DestructibleObject
2. Назови например `BarrelConfig`, `CrateConfig` и т.д.
3. Настрой:

| Поле | Описание | Рекомендация |
|------|----------|--------------|
| Max Health | Сколько урона выдержит | 20-50 |
| Explosion Prefab | Партикл взрыва | Твой prefab |
| Explosion Clip | Звук взрыва | AudioClip |
| Explosion Volume | Громкость | 0.8 |
| Audio Spatial Blend | 0 = 2D везде, 1 = полный 3D | 0.7 |
| Audio Min Distance | Минимальная дистанция звука | 5 |
| Audio Max Distance | Максимальная дистанция | 100 |

### Шаг 3: Настроить объект на сцене

1. Возьми любой объект (бочка, ящик, машина и т.д.)
2. Добавь **Collider** (Box, Sphere, Mesh — любой)
3. Добавь компонент `DestructibleObject`
4. В поле **Config** перетащи созданный Config asset
5. Убедись что Layer объекта входит в Hit Layers оружия

### Шаг 4: (Опционально) Сделать Prefab

Если хочешь расставлять много одинаковых объектов:
1. Настрой один объект
2. Перетащи в папку Prefabs
3. Расставляй на уровне

---

## Как тестировать

### Ожидаемый результат:

1. Расставь несколько разрушаемых объектов на сцене
2. Запусти игру
3. Стреляй по объекту
4. После нескольких попаданий:
   - Появляется партикл взрыва
   - Проигрывается звук
   - Объект исчезает

### Проверки:

| Тест | Ожидание |
|------|----------|
| Стрельба по объекту | Урон наносится |
| Много попаданий | Объект взрывается |
| Звук взрыва | 3D звук (громче вблизи) |
| Несколько объектов | Каждый независимый |

### Если не работает:

| Проблема | Решение |
|----------|---------|
| Урон не наносится | Проверь Collider на объекте |
| Ошибка про Config | Назначь Config в инспекторе |
| Raycast не попадает | Проверь Layer объекта в Hit Layers оружия |
| Нет звука/партикла | Проверь что назначены в Config |

## Разные типы объектов

Можно создать несколько Config'ов для разных объектов:

| Config | Max Health | Описание |
|--------|------------|----------|
| BarrelConfig | 15 | Бочки — легко уничтожить |
| CrateConfig | 30 | Ящики — средняя прочность |
| VehicleConfig | 100 | Машины — много здоровья |

## Архитектура

```
Стрельба игрока
       │
       ▼
WeaponPresenter.PerformRaycast()
       │
       ▼
Physics.Raycast → hit.collider
       │
       ▼
GetComponent<IDamageable>()
       │
       ▼
DestructibleObject.TakeDamage()
       │
       ▼ [health <= 0]
       │
Explode() → Партикл + Звук + Destroy
```

Использует тот же интерфейс `IDamageable` что и враги — никаких изменений в оружии не нужно.
